## Readiness test

For each checked objective, you should be able to:

1. Define the important terms.
2. Name the main files and commands.
3. Read and correct a small configuration.
4. Validate a change before applying it.
5. Find the relevant logs.
6. Explain one common failure and its fix.
7. Complete the matching lab.
